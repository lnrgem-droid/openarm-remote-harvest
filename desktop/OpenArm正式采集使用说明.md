# OpenArm 蘑菇采摘正式数据采集使用说明

更新日期：2026-10-20。笔记本桌面入口为“启动蘑菇采集控制台”；仓库提供的入口名称为“启动正式蘑菇采集”，两者都使用蘑菇采集控制台启动器。

## 连接和版本准备

笔记本连接两条主臂：右臂 `can0`、左臂 `can1`。Jetson 连接两条从臂：右臂 `can1`、左臂 `can2`，以及三台 RGB-D 相机。笔记本有线地址为 `192.168.50.1`，Jetson 为 `192.168.50.2`。

首次使用本次新版前，在 Jetson 开机、采集程序尚未启动时，运行笔记本桌面“更新Jetson采集程序”。等待明确显示软件更新完成。安装器、离线包和部署说明见 `deployment/jetson-offline-update/` 及 GitHub 的 `field-update-20261020` 发布附件。

“现场Jetson连接检查”只检查连接、源码和安装文件，不能代替实际编译模块、相机与短录制验证。临时的“启动临时主从采集测试”连接旧主机 `192.168.50.3`，不要在 Jetson 现场配置中使用。

## 打开界面和开始遥操

1. 双击采集入口。程序配置 CAN、检查网络并启动相机/录制服务，然后打开批次选择和采集界面；此步骤不使能或归位。
2. 确认三路预览正常，选择或新建采集批次。
3. 确认四臂没有夹持物、归位路径无人且无障碍、急停可用、现场有人监护，再点击“开始主从遥操…”并确认。
4. 等待使能、归位、对齐及电机检查完成；期间不要触碰机械臂。只有明确启动成功后才能进行小幅跟随测试。

## 采集

按界面左臂夹持、右臂采摘的任务划分操作，完成对应 READY 确认，再点击相应录制按钮。等待录制开始后执行动作，结束时按实际结果选择“成功并保存”“失败并保存”或中止。等待文件保存完成后再开始下一条。

“保持左臂及夹爪”对应主从两端左臂与夹爪保持，必须等待控制状态确认。电机位置保持不等于机械制动锁，失能后不能依靠该功能承重。

首次到场应分别录制左右臂短样本，确认三路 RGB/深度与关节 state/action 完整，再正式采集。原始图像尺寸和保存格式沿用既有设置；新版修正了已转换毫米深度的比例标注，以及转换脚本使用的关节录制时间起点。

## 结束采集与断电

1. 完成当前录制并保存。
2. 松开夹持物，将主从臂置于失去力矩后也不会下坠的稳固支撑上。
3. 点击“停止遥操并失能…”，等待明确确认 32 个电机均已失能。失败或状态不明不等于失能完成。
4. 点击“结束采集并退出界面”，再关闭机械臂外部电源。
5. 如需拔掉 Jetson 电源，先执行操作系统关机并确认关机完成。

关闭界面本身不会停止遥操；失能按钮不会关闭外部插座或 Jetson。

## 数据与日志

数据保存在 Jetson 的所选批次，默认根目录为 `/home/nvidia/datasets/openarm_harvest_sessions/`。左右臂 episode 分别组织。笔记本显示预览不代表数据已备份到笔记本。

笔记本采集启动日志：`/tmp/openarm-mushroom-collection.log`。离线更新日志：`/home/openarm/openarm-transfer/jetson-update-20261020/update-laptop.log`。遇到错误先保留日志，不要反复启动遥操。
