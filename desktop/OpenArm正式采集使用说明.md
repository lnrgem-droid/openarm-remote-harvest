# OpenArm 蘑菇采摘正式数据采集使用说明

适用入口：桌面上的 **“启动正式蘑菇采集”**。

## 1. 每次采集前

1. 确认主机与 Jetson 都已开机。
2. 主机连接两条主臂：`can0` 右主臂、`can1` 左主臂。
3. Jetson 连接两条从臂：`can1` 右从臂、`can2` 左从臂；三台 RGB-D 相机均连接 Jetson。
4. 确认网线已连接、急停可用、机械臂周围没有人或障碍物。
5. 两人就位：一人操作主臂，一人在从臂旁监护。

## 2. 一键启动

1. 双击桌面 **“启动正式蘑菇采集”**。
2. 终端会依次显示：CAN/网络检查 → 三相机检查 → 从臂归零 → 主臂归零 → 自动对齐 → `RUNNING`。
3. 归零和对齐期间，**不要触碰或移动任何机械臂**。
4. 只有终端最后明确显示：

   ```text
   启动完成：状态 RUNNING
   现在可以遥操：是
   ```

   才能小幅、低速移动主臂测试跟随。

5. 同时会打开“OpenArm Collection Console”三相机实时预览窗口。打开窗口本身**不会开始录制**。

## 3. 采集一条 episode

在实时预览窗口底部操作。

1. 选择本条数据的任务：
   - A：接近蘑菇
   - B：夹取并拔下蘑菇
   - C：放入篮筐
   - D：完整采摘流程
2. 点击绿色 **“开始本 episode”**。
3. 等窗口底部出现“正在本地录制”后，再开始遥操作；录制数据保存在 Jetson，本机只显示 RGB 预览。
4. 完成本条动作后，按真实结果点击其中一个按钮：
   - **成功并保存**：动作完成且结果成功。
   - **失败并保存**：保留失败样本；不要丢弃有价值的失败过程。
   - **中止**：安全中止、误触或本条不应进入训练集。
5. 等提示“已保存 episode_xxxx”后，才能开始下一条。

一场采集可连续保存多条 episode，不会再为每条记录创建许多顶层 `openarm_rgbd_xx` 目录。

## 4. 结束本次采集会话

1. 确认当前没有“正在本地录制”。
2. 点击 **“结束采集会话”**。
3. 若不再遥操，在终端按 `Ctrl+C`；系统会让从臂进入保持。现场人员托住机械臂后，再按既有安全流程执行 `disable` 或断电。

关闭采集窗口只会安全结束当前数据录制，**不会停止遥操**。

## 5. 数据保存在哪里

数据只保存在 Jetson：

```text
/home/nvidia/datasets/openarm_harvest_sessions/<会话名>/
```

每条数据位于：

```text
episodes/episode_0001/
├── episode.json        # 任务、结果、时间、相机健康、帧数、丢帧和质量标记
└── lerobot/
    ├── data/           # LeRobot 从臂状态和实际下发动作
    ├── rgb_raw/        # 左腕、右腕、胸部原始 RGB
    └── depth_raw/      # 三路 uint16 深度与逐帧时间戳 JSONL
```

会话根目录的 `session.json` 汇总这一场采集的所有 episode。

## 6. 重要提示

- 预览帧率低于相机采集帧率是正常设计：Jetson 优先保证本地 RGB-D 保存和遥操。
- `成功并保存` 代表操作结果成功；`episode.json` 的 `valid=true` 还要求三路相机健康、无采集队列丢帧并且每路至少记录 30 帧。
- 这些数据是正式原始采集层；训练前仍需执行后续 OpenArm 验证和 RGB-D 注入到标准 LeRobot 特征的离线转换。
- 如果终端没有最终显示“现在可以遥操：是”，不要移动主臂；保留终端文字或截图后再排查。
