# 远程夹爪闭合阻力修复（2026-09-23）

## 范围与入口

桌面“启动蘑菇采集控制台”仍经 `open_mushroom_collection_terminal.sh`、
`daily_start_teleop_rgbd.sh` 调用同一遥操服务和 `run_bimanual_remote_feedback.sh`。
该核心默认启用 `GRIPPER_CONTACT_FEEDBACK=true`，使用 `install_gripper_candidate`。
无新增桌面入口，不修改采集格式、相机服务、从夹爪增益或关节控制参数。

## 缺陷与修复

旧算法将 `local_dq < -0.02 rad/s` 直接判断为操作者张开，每次把阻力清零。
DM4310 的速度字段采用 12 位、±30 rad/s，量化步长约 0.01465 rad/s。
现场静止采样曾出现 -0.021978 rad/s，因此这个判定会误触发。

现在用本地主夹爪实际位置识别方向：

- 相对闭合方向的最近峰值，张开累计达到 0.003 rad 时撤去反馈；
- 撤去后保持零附加阻力，直到相对张开方向的最近谷值再次闭合 0.003 rad；
- 约 8 个位置量化计数的迟滞，避免单计数位置波动和速度量化反复清空阻力；
- 无效输入、过期许可仍立即清空输出和方向记忆；重新获得许可从零缓升；
- 不根据时间无限积分，不自动闭合主夹爪；张开判断最多延后上述微小位移，
  这段期间附加力矩仍只指向张开方向。

保持原 K=4 Nm/rad、0.01 rad 开度死区、0.40 Nm 附加反馈上限及 2 Nm/s 增力斜率。
这不是从夹爪力矩上限，不是力传感器读数，也不能保证菌棒夹牢或防止从夹爪过热。

## 软件验证

- 注入现场量化速度（-0.007326/-0.021978）与 ±1 位置计数，仍保持 >0.35 Nm 阻力。
- 验证慢速张开累计位移释放、释放后静止不重新加力、再次闭合从 -0.004 Nm 起坡。
- 原有空载、限幅、过期、越界、NaN、CAN8失能/故障/过期测试保留。
- 主机相关遥操、协议、看门狗、采集姿态、跟踪及夹爪测试 93 项通过。
- 主机 x86 与 Jetson ARM 原生编译完成；原始 `install`、旧 `install_bimanual` 保留。
