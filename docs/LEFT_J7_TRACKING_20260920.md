# 左从臂 J7 静态跟踪偏差：首轮诊断与调整

2026-09-20，用户报告主臂手腕伸直后，从臂仍下垂；用户确认无线缆拉扯或硬阻挡。

## 原始实测

持续 5 秒以上读取左臂，状态 RUNNING / FOLLOW，动作约 0.5–1.3 ms、反馈约 1.5–6.3 ms。

- 主臂 J7：−0.905432 rad（−51.877°）。
- 网关下发 J7：与主臂一致。
- 从臂 J7：约 −0.784504 rad（−44.949°）。
- 持续静态偏差：−0.120928 rad（−6.929°）。
- 实际 can2 ID 007 MIT 报文 `76B97FF051199788`：目标 −0.905814 rad，量化 Kp≈9.890、Kd≈0.499、前馈约 −0.584 Nm。
- Jetson 实际生效关节限位文件 J7 为 ±1.570796 rad，不是 ±45°。目标也未在控制器截到 −45°。

因此可以定位为目标已经到达电机后的物理跟踪偏差，而非网关目标偏移或网络延迟。单个姿态不能进一步唯一确定负载模型误差、摩擦或其他机械原因；不以此直接修改零点或增加恒定角度偏置。

## 首轮修改

控制器增加 `left_kp/left_kd/right_kp/right_kd` 可选七元素覆盖；为空则沿用公共 kp/kd。初始化 CAN 前检查元素数量、有限数值和 MIT 协议增益范围。两臂使用独立参数副本。

仅双机双臂从端配置覆盖左 J7：Kp 10→15，Kd 0.5→0.6。左其他关节、右臂、主臂、启动归位参数、力反馈参数、速度和安全限制均不变。

主机 x86 和 Jetson ARM 编译通过；68 项控制/参数回归通过。Jetson 日志与实际 CAN 报文确认新增益生效；主机日志确认其公共增益未受影响。

部署时使用原受控启动流程。左臂归位日志出现最大误差约 0.101 rad（J4），高于内部归位目标 0.07 rad；原启动逻辑随后依据主从对齐阈值完成 ALIGN/RUN，本次没有放宽阈值或跳过门限。该残余误差不能被描述为所有关节精确归零。

## 当前验证边界

部署后恢复 RUNNING、双臂 FOLLOW、未录制。当前近零姿态左 J7 主臂约 −8.994°、从臂约 −6.393°，偏差约 −2.601°。

这不是原 −52° 姿态，不能直接把 6.9°→2.6° 宣称为同条件改善率。

操作者随后恢复近似伸直姿态：主臂 −55.287°、从臂 −51.746°，连续 16 次采样误差 3.541°，双方角度变化范围均为 0，fault_bits=0。该姿态与原姿态接近但不完全一致，只能说明改善趋势，不能声称严格的同条件改善率。

据此进行第二档小步试调：仅左从 J7 Kp=20、Kd=0.7，其他参数不变，等待近似原姿态复测。若出现振荡或自行运动，应立即停止测试，不继续提高增益。

第二档复读：16 次、约 5 秒的静止采样中，主臂与目标均为 −27.026°，从臂为 −24.360°，静态偏差仍为 2.667°，J7 读数范围为 0，全部返回 RUNNING / fault_bits=0。该姿态不是先前 −52°～−55° 的伸直姿态，不能用于声称第二档在原姿态的改善率，也不能将静止采样无变化等同于动态无振荡验收。当前保留第二档试调值，未继续提高增益；同姿态复测和动态手感仍待完成。
