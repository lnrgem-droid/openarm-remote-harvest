# 左从夹爪故障恢复记录（2026-09-22）

## 现象与证据

左主夹爪操作后，左从夹爪不动。上层为 RUNNING，左右均为 FOLLOW，无录制。
被动监听证实左从 `can2/8` 持续返回状态 `0xC`，左主及右从夹爪正常使能。
厂家手册将 `0xC` 定义为电机线圈过温故障。

恢复前只读查询显示：左右从夹爪的 OT_Value 均为 100℃；左从实时反馈 MOS
35℃、线圈 33℃。这只能证明读取时温度已低，不能据此确定此前真实最高温度，
也不能排除测温异常。未修改任何温度阈值、CAN 波特率、编码器零位或控制增益。

## 本次一次性恢复

1. 操作者明确确认夹持物已取下，手指远离，允许单夹爪恢复和小幅测试。
2. 起初从夹爪实际约 -1.03437 rad、目标约 -0.52205 rad，未直接清错使能，
   避免恢复后突然闭合半程。
3. 操作者将左主夹爪张开；读到目标 -1.0472 rad，与从夹爪相差约 0.01283 rad。
4. 通过现有 `left_lock` 暂时冻结左臂目标。右臂模式不变，未重启控制栈。
5. 仅向 Jetson `can2` 的电机 ID 8 发送一次清错；反馈由 12 变为 0。
6. 仅对同一电机发送一次使能；反馈变为 1。没有向其他电机发送状态控制命令。
7. 连续 3 秒、2986 条反馈全部正常；实际位置范围
   [-1.04200046, -1.04161898] rad，MOS 35℃、线圈 33℃。
8. 通过原有 `left_follow` 对齐门槛恢复跟随，未绕过安全状态机。

此次处理是运行时故障恢复，不是永久解决过温原因。不得设置自动循环清错/使能。
若再次出现，停止夹持测试，检查长期堵转、夹指行程/负载和温度反馈。

## 未闭环项

- 上层 RUNNING 未反映该夹爪故障；需单独完善夹爪健康显示和故障传播，不能把
  RUNNING 作为八个电机全部正常的证明。本次未热替换控制代码。
- 静态使能恢复不等于完整夹持验收；实际开合、夹物手感和长时间温升仍需验证。
