# 远程夹爪受阻反馈（2026-09-20）

## 目标与单机代码对照

目标：从夹爪夹到物体不能继续闭合时，操作者继续捏主夹爪能感到反向阻力。
不是提高从夹爪夹持力，不是自动判断菌棒已经夹牢。

原程序 `openarm_teleop/control/openarm_bilateral_control.cpp` 将从夹爪实际状态作为主夹爪参考，
`openarm_teleop/config/leader.yaml` 的夹爪 Kp=4.0、Kd=0.1；电机执行位置反馈。
原双机程序为0.8Nm/rad的远程虚拟弹簧，主端额外反馈项被限制为±0.20Nm，较小闭合误差的阻力偏弱。
该对照说明了实现差异，不等于已经辨识实际机构摩擦或测量用户手感。

## 本次实现

- 复用UDP状态回传，不增加网络端口，不修改协议长度或从夹爪控制参数。
- 主机网关在私有 `/leader/{left,right}_arm/force_feedback` 消息的 `position` 中附带一个值：
  从夹爪实际电机角度rad。它不是普通 `joint_command`；原八维 `effort` 保留用于兼容。
- 控制器在主机本地500Hz，比较本地主夹爪实际角度与远端实际角度；不使用启动开度偏移。
- OpenArm的张开方向为负、闭合为0。附加力矩采用
  `clamp(4 × (从夹爪角度 − 主夹爪角度 + 0.01), −0.40, 0)`。
  约0.57°死区吸收小跟随误差；阻力增大速率不超过2Nm/s，不积分。
- 只抵抗继续闭合，不主动拉主夹爪闭合。主夹爪向张开方向运动超过0.02rad/s时撤去附加阻力；
  当角度差消失时立即撤去，不保留“接触记忆”。原局部Kd阻尼保持不变。
- 上限0.40Nm是主夹爪**附加反馈项**上限，不是总电机力矩上限，更不是指尖夹持力上限。
- 只在RUNNING、对应臂FOLLOW、反馈有效时附带位置；同一Jetson时钟域内观测帧龄须≤50ms。
  原有网络会话、序列号及回执新鲜度检查继续生效。
- 主端另用只收不发的CAN反馈检查，要求夹爪电机8真实使能且反馈≤50ms；本地ROS反馈流超过
  50ms没有刷新也撤去该附加项。左右HOLD、右臂专用回位、启动归位不启用此项。
- 两只夹爪使用同一实现；七个关节的反馈增益、重力补偿、从臂夹爪Kp/Kd均未调大。

这是参考单机位置反馈原理的**单向闭合阻力提示**，不是照搬单机双向位置伺服，
也不是从夹爪实测接触力的等比例回传。快速操作时网络延迟仍可能产生额外手感，需要实物验收。

## 构建与回退

两端独立编译至 `ros2_robot/install_gripper_candidate`，不替换先前通过归位验收的
`install_tracking_candidate`，不修改原始单机代码。
核心脚本 `GRIPPER_CONTACT_FEEDBACK=true` 选择新构建及主端新功能；
明确设置false则回到上一套跟踪纠偏构建。不要在已有控制栈运行时并行启动另一个核心脚本。
ROS launch的夹爪新开关仍默认false，只由核心入口显式开启。

主机依赖使用系统Python3及系统yaml-cpp，不能链接Conda动态库；构建方式与
`TRACKING_HARDWARE_ACCEPTANCE_20260920.md`相同，将三个构建目录后缀改为`gripper_candidate`。
Jetson在ARM64本机编译，不复制主机二进制。

## 验证记录

- 主机完整回归115项通过，Jetson相关测试50项通过；两端C++和运行时编译通过。
- 测试直接调用生产C++：空载同角度无附加力、0.1rad受阻间隙稳态−0.36Nm
  （旧式理论值−0.08Nm）、限幅、增力斜率、长时间受阻不累积、主动张开撤去、过期撤去、
  NaN/越界拒绝、CAN电机8失能/故障/过期拒绝。
- Python检查左右保持互不干扰、READY/故障不反馈、旧观测及未来时间戳不反馈。
- 软件计算通过不等于夹实物手感已验证；实际阻力强弱、松开是否顺畅需现场操作者确认。
- 经用户确认取下物体后，已重启原遥操服务：四臂归位、两轮对齐和32电机使能检查通过。
  主端实际运行日志确认 `Gripper contact reflection: enabled`；双臂RUNNING/FOLLOW，无故障。
  尚待用户夹实物确认触觉效果，不把启动成功写成手感验收通过。

## 实物试用

遥操完成归位且进入RUNNING后，先空载缓慢开合右主夹爪；再用有支撑、不易碎的物体试夹。
手指不能放到从夹爪夹点。碰到物体后只轻微继续捏主夹爪，确认阻力增加；然后主动张开，
确认从夹爪松开且主夹爪不自行闭合。不要通过使劲捏到底来证明效果。
如无阻力、阻力方向相反或出现抖动，停止试夹并反馈，不继续增加反馈上限。
