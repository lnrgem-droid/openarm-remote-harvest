# 夹物后主夹爪阻力消失：现场记录与候选修复

## 只读现场证据

2026-09-23，左从夹爪夹物时：左主夹爪 can1/8 位置约 -0.571641 rad，左从 can2/8 约 -0.875296 rad，相差约 0.30365 rad（17.4°）。两个电机均为使能状态 1。主机 ROS 力反馈话题连续收到从夹爪的实际角度，且反馈功能已启用，但主夹爪 CAN 附加力矩约为零（编码零点约 -0.00244 Nm）。从夹爪电机报告约 3 Nm，不是指尖牛顿值。

持续夹持时线圈温度从 71°C 升到 77°C。已通知操作者托稳、松夹取物，没有自动开合、失能或重启。松夹后力矩接近零，温度一度为 78–79°C；操作者确认取物后，后续读数为 57°C、约 0.05 Nm，无电机故障码。

## 可复现缺陷

上一版方向迟滞算法在主夹爪张开 0.003 rad 后将阻力清零，并保持在 opening 状态。只要未再次达到闭合迟滞门槛，即使从夹爪仍被挡住、主从开度差很大，也持续没有阻力。

使用相同生产类模拟：从夹爪 -0.875296 rad；主夹爪先 -0.567 rad，再轻微张开到现场的 -0.571641 rad 并静止。旧算法持续输出 0，新算法稳定输出 -0.40 Nm。此复现证实该逻辑缺陷；尚未通过切换后的真机 CAN 与夹物手感验证它是现场全部原因。

## 候选修复

删除持续撤力方向锁存，采用有界单向开度弹簧：

`goal = clamp(4 * (remote_q - local_q + 0.01), -0.40, 0)`

只向张开方向施力，反对继续闭合；张开到与从夹爪开度一致/更开时反馈消失。张开过程中若开度差仍很大，反馈会辅助张开，而不是像旧版立即清零。它不是机械锁，操作者仍可能克服最大阻力；不能承诺完全无法继续闭合。

保持 2 Nm/s 增力斜率、0.40 Nm 上限、输入范围/有限值校验、反馈超时、驱动健康、归位与独立臂模式保护。从夹爪增益和夹持力未提高。不增加堵转保持力，不将电机力矩冒充指尖力。
