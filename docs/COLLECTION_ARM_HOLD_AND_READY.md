# 左臂保持与右臂起始位：使用说明及验收记录

更新：2026-09-18。入口仍为桌面“启动蘑菇采集控制台”。

## 实际操作

1. 等待遥操显示 RUNNING，先用左主臂将左从臂移动到菌棒旁并夹稳。
2. 点击“保持左臂及夹爪”。看到“保持中”后，可以松开左主臂；左从臂继续保持当时的关节与夹爪目标，右臂继续跟随。
3. 第一次采集或更换作业布置时，将右臂遥操到合适的采摘准备位置，保持静止，点击“保存起始位”。同时保存夹爪开合目标。覆盖原位置会弹出确认。
4. 下一条右臂采集前，先将采下物体放好，点击“回到起始位”。确认路径没有菌棒、货架等阻挡。右从臂以低速返回，夹爪恢复保存的目标。此时不能开始录制。
5. 显示“保持中”后，手动将右主臂和主夹爪对齐。界面显示最大差值；差值 ≤0.06 rad 后点击“对齐后恢复跟随”。未对齐会拒绝恢复，避免从臂突然追赶主臂。
6. 确认右臂 READY 和单朵目标，点击“开始录制右臂”。动作与三路 RGB-D 保存到 Jetson。回位和主臂重新对齐过程不进入本条数据。
7. 点击“成功并保存”“失败并保存”或“中止本条”。封装期间仍保持左臂，右臂遥操继续；封装完成后可以再次回位采下一条。
8. 需要重新调整菌棒时，将左主臂及主夹爪对齐到保持目标，点击“对齐后恢复左臂跟随”。录制或封装期间不能解除保持。

右臂回位过程中可随时点击“停止回位”。它进入当前位置保持，不自动恢复跟随；可以重新回位，或对齐主臂后恢复跟随。回位期间关闭窗口会先请求停止回位，确认保持后再关闭窗口。

结束录制、关闭采集窗口，不会自动解除左臂保持，也不会使机械臂断力。

## 起始位保存与适用范围

Jetson 文件：`/home/nvidia/openarm-rgbd-runtime/right-start-pose.json`。

文件保存右臂七关节、夹爪的目标值和实测值，以及型号、版本和时间。重启后保留。当前保存的是自动验收时的准备姿态；首次实际采摘前请重新保存你的作业起始位。

位置以机械臂基座为参考。移动底盘、升降杆或改变夹指/负载后，应重新检查起始位及回位路径。回位采用关节插值，不具备货架避障能力。

## 实现细节

- 左臂保持锁存正在下发的目标，而不是将夹爪目标改成受阻时的实测开度，以保留原有夹持预紧。主臂动作不再覆盖该目标。
- 左主臂的双边反馈在保持期间置零，原有重力补偿继续工作。切换左臂时不重置右臂的力反馈参考。
- 右臂保存起始位要求反馈健康且静止；文件通过临时文件、fsync 和原子替换保存。检查有限数值、v10 右臂限位（包含 J2 的 +π/2 偏置）、型号及目标跟踪误差。
- 回位使用五次平滑插值，关节目标峰值速度不超过 0.15 rad/s，夹爪目标不超过 0.25 rad/s。时间至少 2 秒；到位误差要求关节 ≤0.06 rad、夹爪 ≤0.1 rad，并稳定 0.5 秒。
- 关节目标跟踪误差超过 0.20 rad 或到达轨迹时间后再等 8 秒仍未到位，停止回位并保持。网络、看门狗许可或任一臂反馈变旧时，立即取消回位；网络恢复不会自动继续。
- 恢复跟随要求主臂与保持目标（包括夹爪）的差值 ≤0.06 rad，随后进行限速过渡。右臂回位完成后始终先保持。
- 录制管理器在创建正式左右 episode 前向 Jetson 控制器申请带标识的录制锁。右臂录制要求左臂保持、右臂跟随、已保存起始位且实际关节距该起始位 ≤0.07 rad。自动回位或过渡期间拒绝开始。
- 从准备录制到封装完成，禁止回位、覆盖起始位和解除保持。录制结束不停止遥操；管理器记录开始时的保持状态和起始位到 `episode.json` 的 `collection_motion_at_start`。
- 管理器在录制过程中检查控制器状态和录制锁；控制许可丢失则请求结束该条数据。
- 左右臂反馈时间分别记录，任一臂反馈停止都不能被另一臂的新反馈掩盖。
- UDP 状态包 header flags 增加左/右局部保持标志（位 0 / 位 1），供主机抑制对应的力反馈。协议包和主从网关必须配套更新；启动脚本增加导入检查。

当前仍是位置保持，不是指尖恒力控制。没有新增指尖力传感器；保持预紧不等于已经确认菌棒无滑动，也不能补偿掉电后的失力。
